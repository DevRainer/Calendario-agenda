# 📅 Calendário com Anotações

Este projeto é uma página web simples que exibe um calendário com possibilidade de adicionar anotações.  
O objetivo é fornecer uma interface limpa e centralizada, com fundo personalizado.

---

## 🚀 Funcionalidades
- Exibição de calendário.
- Área para anotações e lembretes.
- Layout centralizado utilizando **Flexbox**.
- Imagem de fundo personalizada.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** → Estrutura da página.
- **CSS3** → Estilização e centralização do conteúdo.
- **JavaScript (opcional)** → Para manipulação dinâmica das anotações (se implementado).
